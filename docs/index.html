基本操作

通常キー

基本レイヤーはQWERTY配列です。キーを短く押すと表示された文字や記号を入力します。

長押しとレイヤーキー

MT は短押しで文字、長押しで修飾キーになります。LT n は押している間レイヤー n を有効にし、短く押すと右側に書かれたキーを入力します。

レイヤーの見方

Windows用とMac用の基本レイヤーを切り替えて使います。レイヤー2はポインター操作時に一時的に有効になります。レイヤー4〜9は親指キーを押している間だけ使います。

このファームウェアのタップ／ホールド判定は、複合キーがバランス型、レイヤータップがホールド優先（クイックタップ200ms）です。

親指レイヤーの使い方

基本レイヤーの親指キーは、単独タップでSpace、Backspace、Enter、Tabなどを入力し、長押し中は対応するレイヤーを開きます。Windowsは LT 4〜LT 10、Macは LT 5〜LT 11 を使います。

マウス操作レイヤー

レイヤー2でクリック操作を行えます。レイヤー3ではポインターがゆっくり動きます。右側のトラックボールを動かすとレイヤー2が一時的に有効になり、操作を止めると戻ります。

同時押しコンボ

「位置」はZMKの物理キー位置番号です。記載されたキーを同時に押します。レイヤー条件に合うときだけ発動します。位置はKeymap Editor上のキー位置と照合できます。

ポインティングとジェスチャー

  • トラックボールを動かすとオートマウスレイヤー（2）が約150ms有効になり、レイヤー上のクリックや戻る／進むを使えます。
  • 47・48・49番キーを同時に押すと低速マウス（3）になります。速度は通常の1/5です。
  • Windowsジェスチャーレイヤー（8）でボールを左右に動かすと仮想デスクトップを切り替え、上下でウィンドウサイズを変更します。
  • Macジェスチャーレイヤー（9）では同じ方向操作でMission Controlのデスクトップ移動・ウィンドウ表示・縮小表示を実行します。Caps LockをGlobeキーとして設定してください。
  • スクロールレイヤー（10／11）ではトラックボールの動きがスクロールになります。Windowsは標準速度、Macはより遅い設定です。
Macの準備：「システム設定」→「キーボード」→「キーボードショートカット」→「修飾キー」でCaps LockをGlobeキーに割り当てます。ジェスチャーでウィンドウを整列する機能を有効にしてください。

Bluetoothとメディア操作

  • レイヤー10／11のBluetoothスロットキーでスロット0〜4を選びます。選択と同時にWindows／Mac配列も切り替わります（0・2・4はWindows、1・3はMac）。
  • 同じレイヤー内のBluetooth切断キーは、指定スロット0〜4のペアリングを切断します。
  • BT CLR コンボは現在のスロットのペアリング情報を消去します。BT CLR ALL コンボは登録済みペアリングをすべて消去します。消去後は各端末で再ペアリングしてください。Bluetooth切断キー（BT DISC 0〜4）は該当スロットとの接続を切ります。
  • レイヤー10／11には音量ダウン、ミュート、音量アップ、前の曲、次の曲、一時停止／再生があります。

キーマップの変更

キーマップは config/keymap.keymap で定義されています。Keymap EditorまたはZMK Studioでも編集できます。変更後は左右それぞれに合ったファームウェアを書き込みます。トラックボール搭載側には _central、反対側には _peripheral のUF2を使います。

4方向スイッチや高解像度ダイヤル搭載モデルでは、ビルド時の入力デバイス設定に応じて追加ボタンとダイヤル動作が有効になります。高解像度ダイヤルは基本レイヤーでスクロール、Macレイヤーで低速スクロール、オートマウスで音量調節、低速マウスでRadial Controller操作を行います。

このガイドはリポジトリ内の標準キーマップ設定をもとに作成しています。キー位置番号は config/keymap.keymap のコンボ定義と対応します。
