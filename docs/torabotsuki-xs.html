01 / START HERE

まずは、この3つ。

1

短く押すと、文字。

Spaceタップ → 空白

大きな表示は短押しの動作。通常のキーはそのまま入力します。

2

押したままで、別の配列。

Space長押し：数字＋ J → 4

Spaceを押したままJの位置を押すと「4」。Spaceを離すと元の配列に戻ります。

3

一緒に押すと、コンボ。

J + K→ 左クリック

指定したキーをほぼ同時に押します。1本ずつ順番に入力する操作とは異なります。

図の前提：この取説は config/keymap.keymap の現在の設定に対応します。リポジトリにXS専用の物理形状定義がないため、文字キー3段と下段の操作キーを抜き出した位置関係の模式図です。実機の外形・キー間隔・キー数を保証する図ではありません。図中の薄い「—」は無効キーです。

02 / KEYMAP EXPLORER

親指を添えて、配列をひらく。

表示するOS

この切替は説明図の表示だけを変えます。実機は Q＋W でWindows、Q＋W＋E でMacへ切り替えます（L0・L1の両方で有効）。接続先を変えずに配列だけ切り替えます。

レイヤー一覧

番号・入り方から選ぶ

L2はOS共通です。L3は欠番です。ボール移動による配列の自動切替はありません。

このレイヤーのコンボ

コンボを選ぶと、上の配列図で押す位置を強調します。

レイヤー・接続操作長押しで修飾キー下位レイヤーから引継ぎ

キー右上の小文字は基本配列での位置名、下の小文字は長押しや接続先選択の動作。点線のキーは通常、基本配列の動作を引き継ぎます。各キーにポインターを重ねると設定値を確認できます。コンボで使う名前は基本配列上の位置名です。

記号は日本語（JIS）配列を想定

括弧や記号はJIS配列での出力を表示しています。PC側のキーボード設定がUS配列だと、一部の記号が図と異なります。

Ctrl = Control、Cmd = Command、Win = Windowsキー、Alt = MacではOptionです。Bspc はBackspace。

例：記号レイヤーで J＋K → +、K＋L → *。同じ位置でもレイヤーで意味が変わります。

Shiftは左親指へ：左親指左側（旧Bspc）の短押し1回で、次の1キーだけShift入力になります（図のShift¹）。短押しを素早く2回行うとCaps Lockのオン／オフを切り替えます（連打の判定200ms）。単押しの確定は最大200ms待ちますが、その前に別のキーを押すと直ちに確定し、そのキーにShiftが付きます。Sticky Shiftの有効時間は確定後1500msです。200ms以上押すか、押したまま別のキーを押すと通常のShiftになり、離すまで有効です。MacでCaps LockをGlobeに割り当てている場合、2回押しもGlobeになります。Caps Lockとして使う場合はOS側の割り当てもCaps Lockにしてください。Zと右小指の/は文字入力専用。記号レイヤーのZ位置はUndo専用、/位置は基本配列の/を引き継ぎます。Backspaceは右下段に残しています。

03 / TOGETHER

同時に押す場所が、ひと目で。

左手 · 英数

S ＋ F

薬指と人差し指を同時に。間のDは押しません。

右手 · かな

J ＋ L

人差し指と薬指を同時に。間のKは押しません。基本配列でKも押すと中クリックです。

色のついたキーを一緒に押します。図は基本配列の位置名で表示します。上のOS・レイヤー選択と連動して、現在のレイヤーで有効なコンボを強調します。他のコンボも一覧に残しています。

2キーと3キーなど、押す場所が重なるコンボがあります。3キー操作は3つをそろえて押してください。英数・かなはそれぞれ LANG2・LANGUAGE_1 を送信します。実際の入力モード切替はOS・IMEの設定に依存します。マウスの「戻る／進む」はボタン4／5の送信です。

04 / POINT & MOVE

ボールに、もうひとつの役割。

基本配列のまま

なじんだコンボでクリック。

↗＋
J＋K 左クリック

ボールを動かしても配列は切り替わりません。J＋K が左、K＋L が右、J＋K＋L が中クリックです。

ドラッグはクリックのコンボを押したままボールを動かします。戻るは M＋,、進むは ,＋.。旧オートマウスのL2は、Bluetooth管理レイヤーとして使います。

一定の速度で操作

マウス操作はコンボに統一。

低速マウスと、M＋,＋.で速度を切り替えるコンボは廃止しました。ボールは通常速度で動き、J・K・Lは単独では文字入力です。

戻る／進むは2キーのコンボを使います。M＋,＋.の3キーは専用の操作ではなく、既存の戻る／進むコンボと重なるため使わないでください。

Enter長押し / L10・L11

ボールでスクロール。

Enter押したまま＋↕

Enterを長押しして右ボールを動かすとスクロールします。押したまま J を1回押すと縦のみ、K で横のみ、H で縦横自由に切り替わります。H・J・Kは離してもモードを保持します。Enterを離すと解除され、次回は自由スクロールから始まります。設定上のスクロール倍率はWin：1/2、Mac：1/12です。M / , / .で音量−・ミュート・音量＋、中央右のTabで再生・一時停止も操作できます。BTの切断・削除はL2へ移しました。

現在のビルドは左ミニトラックパッドもスクロールモードです。右ボールのレイヤー処理とは別経路で動作し、H・J・Kによる軸制限は適用しません。

F・ジェスチャ長押し / L8・L9

4方向で、ウィンドウ操作。

Spaceの右隣のキーを押したまま、右ボールをいずれかの方向へ動かします。この間、通常のポインター移動は止まります。

WindowsはWin＋矢印、MacはCtrl＋Caps Lock＋矢印／F／Cを送信します。MacはREADMEの設定に合わせてCaps LockをGlobeへ変更する想定です。実際の動作はOS側のショートカット設定に依存します。

検出の移動量は100、クールダウンは100ms。下図の方向は処理後のポインター座標で、実機のボールを回す向きとは反転する場合があります。

05 / CONNECTION

接続先は、5つのスロットに。

右手だけで、接続先を選ぶ

  1. 基本配列で、入力を200ms以上休める。
  2. H＋J＋K をほぼ同時に押す（3キーを50ms以内）。
  3. 3キーをすべて離してから、下の Y / U / I / O / P を1回押す。

専用のL2で選択するため、Enterの長押し判定には依存しません。接続先とWindows／Macの配列が切り替わり、基本配列へ自動で戻ります。選択前なら Enter・Esc、または再度 H＋J＋K で、接続先とOSを変えずに戻れます。A〜Gの切断と登録削除コンボもL2で使います。

基本配列 L0 / L1H＋J＋K → 離すBluetooth管理 L2Y〜Pで選択 → 基本配列へ
A〜Gで切断・コンボで削除 → L2のまま
Y0Windows
U1Mac
I2Windows
O3Mac
P4Windows

Enterを長押ししながらのQ/W/E/R/T・Y/U/I/O/Pによる選択と、前／次スロットへの切替は外しています。スクロール中に接続先が変わらない構成です。

はじめて接続する

  1. PC・タブレットのBluetooth設定を開く。
  2. H＋J＋K → すべて離す → Y/U/I/O/Pで未登録のスロットを選ぶ。
  3. 接続先でキーボードを選び、ペアリングする。

登録済みスロットは、その接続先への再接続に使います。

L2で切断する

H＋J＋Kを押して離した後、A / S / D / F / Gでスロット0 / 1 / 2 / 3 / 4を切断します。登録は保持します。

切断後はL2に留まります。EnterかEscで元の基本配列へ戻ります。

登録を消す操作（L2のみ）：H＋J＋Kを押して全部離し、左下段の修飾キー3つ（位置53・54・55）で現在のスロットの登録を削除。Q＋W＋E＋R で全スロットの登録を削除します。再接続には接続先側の登録も削除し、ペアリングし直してください。削除後もL2に留まるので、EnterかEscで戻ります。特定のスロットを消す場合は、その接続先を一度選んでからL2を開き直してください。単なる切断には上のA〜Gを使います。
06 / REFERENCE

迷ったときの確認先。

意図したキーが出ないとき

  • OS配列を確認：L0・L1のどちらでもQ＋WでWindows、Q＋W＋EでMacへ。接続先は変わりません。
  • Bluetooth管理のL2にいる：EnterかEscでキャンセルできます。
  • H＋J＋KでL2が開かない：入力を一呼吸休めて、3キーをそろえて押してください。
  • 記号のずれ：PC側がJIS配列になっているか確認。
  • ボール移動でJ・K・Lがクリックになる：旧ファームウェアではオートマウスが有効です。今回の変更をビルド・書込みして反映してください。
  • 長押しで文字が出る：先にレイヤーキーを押したままにしてから、対象キーを押す。
  • Macのジェスチャ：READMEにあるCaps Lock → Globeの設定を確認。

この取説の設定元

  • キー・コンボ・マクロ
  • 右ボールのレイヤー処理
  • 現在のビルド構成：右がcentral、左がperipheral。現在の構成ではダイヤル・4方向スイッチは未使用。
  • README / Mac側の設定

Studio等で実機の配列を変更した場合、この取説と異なることがあります。親指Shiftは専用のhold-preferred（200ms）の短押し側にTap Dance（200ms）を組み合わせ、単押しをSticky Shift（1500ms・quick-release）、2回押しをCaps Lockにしています。長押し側は通常のShiftです。ほかのMTはbalanced、LTはhold-preferredです。LTのquick-tap-msは200（再タップの判定値）で、長押しの閾値そのものではありません。
