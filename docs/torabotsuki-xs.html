OS側の初期設定

使い始めに1回、配列と修飾キーを設定します。

DYA Studioでキー・接続先・ポインターを調整する

左右ともDYA対応ファームウェアを書き込み、右側をUSB接続します。接続管理で左親指Shift位置を押してStudio解除、Enterで戻り、Chrome／Edgeから接続します。ポインティング設定は mouse＝右ボール、scroll＝右ボールのスクロール、pad＝左パッド。初期倍率はすべて1で、OS別速度を引き継ぎます。ジェスチャーは専用経路です。

DYA側の接続先選択では配列は変わりません。WindowsはQ＋W、MacはQ＋W＋Eで切り替えます。対応範囲・移行・保存と実機確認の手順。

Windows

  1. OSのキーボード配列を日本語（106/109）にする。
  2. キーボードで Q＋W を押し、Windows配列にする。
  3. 配置ジェスチャーを使う場合は「設定 → システム → マルチタスク」のウィンドウのスナップを有効にする。

Mac

  1. OSのキーボードの種類をJIS（日本語）にし、キーボードで Q＋W＋E を押す。
  2. 配置ジェスチャー用に「システム設定 → キーボード → キーボードショートカット → 修飾キー」で、このキーボードのCaps Lock → Globeを設定する。

Capsを入力切替に使うソフトを利用中なら、Globeへの割り当てとの競合を確認してください。

日英切替の補足と代替案

現在の配列では、S＋Fで英数、J＋Lでかなへ直接切り替えます。MacのSpace右隣は、短押しで左Ctrl、長押しでFキーの配列です。

追加ソフトを使わない代替案として、ZMKから右Ctrl＋Spaceを送る &lt 9 RC(SPACE) があります。ただしmacOSの入力ソース切替を呼ぶ方法で、選択表示や待ちが生じます。Windowsの半角／全角と同じ即時トグルの代替にはなりません。現在のキーマップには適用していません。

macOS標準のCapsによる入力切替も利用できますが、上のCaps → Globeとの併用は割り当てを調整する必要があります。親指ShiftからCapsは送信しません。

画面ズームを使う場合

Macの「システム設定 → アクセシビリティ → ズーム機能」で「スクロールジェスチャと修飾キーを使って拡大縮小」を有効にし、使用する修飾キーを選びます。

Globeキーとショートカットの補足

配置ジェスチャーは右Ctrl＋Capsと方向キーなどを送信します。Mac用マクロ名は mac_window_*、表示ラベルは MAC_WINDOW_*（LEFT／RIGHT／SMALL／LARGE）です。Caps → Globeの割り当てを使う前提です。ZMKの &kp GLOBE はApple純正のFn／Globeを完全には再現しません。

Apple：修飾キーの設定 ／ ZMK：キー仕様

ジェスチャー・スクロールの仕様と確認項目

タブ切替はL3、ウィンドウ配置はL8／L9、スクロールはL10／L11。数字・記号配列でも親指Shift保持でタブ切替を使えます。F・Enterの操作は親指Shiftより優先。タブ切替の上下は未割当で、解除時に途中の動きをリセットします。

ジェスチャーは stroke-size=100、gesture-cooldown-ms=100、eager mode。右ボールの処理は boards/shields/torabo_tsuki_lp/torabo_tsuki_lp_right.overlay、送信キーは config/keymap.keymap を参照します。

タブ切替ビヘイビアの引数は two_param.yaml から継承する param1（Windows）と param2（Mac）です。binding-cells の名前を上書きするとZephyrのdevicetree生成で失敗します。

H／J／Kの軸選択はEnterを離すまで保持し、次回は自由に戻ります。U／Oは明るさ−／＋、M／,／.は音量−／ミュート／＋、Tab位置は再生・停止です。

書き込み後の確認：Windows／Macの基本・数字・記号配列で左右のタブ切替、Macの右Ctrl／Windowsの左Ctrl送信、配列の往復切替後の動作を確認します。未割当の上下、解除後のポインター復帰、途中の動きのリセット、F・Enterの優先、H／J／Kの保持と解除、左パッドが軸制限の影響を受けないことも確認します。実機動作は未確認です。

Bluetoothの構成・設定値・確認項目

ホスト7枠＋左右間通信用1枠。中央側専用の snippets/split-central/split-central.conf で CONFIG_BT_MAX_CONN=8・CONFIG_BT_MAX_PAIRED=8 を設定します。周辺側には適用しません。現在のビルドは右側が中央です。

登録削除コンボはL2のみ。現在のスロット削除は位置32・33・34、全登録削除は位置0・1・2・3です。L2は無関係な文字・クリック入力を無効にしています。

書き込み後の確認：両基本配列からL2を開き、Hで5（Mac）、Jで6（Windows）を選んでペアリングし、0〜4へ戻れることを確認します。Z／Xによる5／6の切断、Enter／Escによる終了、左右のキー入力も確認してください。実機動作は未確認です。

Bluetooth登録を残すファームウェア更新

ブートローダー起動 → 左右の通常UF2を直接コピー → 元の接続先へ。毎回の settings_reset は不要です。これを書き込むとBluetooth登録も消えます。Studioの保存配列だけを戻す場合はRestore Stock Settingsを使います。通常更新と全設定リセットの手順。

42キー配列・軽量化・旧配列からの移行

既定はSサイズの42キー。右最下段のBspcとHomeの間はボール専用で、キーを定義しません。M・Lの選択肢は外し、全12レイヤーとコンボの位置番号を揃えています。Studioに旧66キー配列を保存している場合は、バックアップ後に新しい既定配列へ戻します。測定結果・移行手順・確認方法。

設定元・ビルド・資料

操作ガイドは config/keymap.keymap を元にしています。配列・コンボ変更時は python docs/generate-keymap.py で docs/keymap-data.js を再生成します。生成データは手編集しません。

ビルド構成は build.yaml と .github/workflows/build.yml。ファームウェアのビルド・実機検証と、HTMLの表示確認は別の検証です。Studioで実機を変更した場合は図と異なることがあります。
