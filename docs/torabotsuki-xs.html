レイヤー・接続操作長押しで修飾キー下位レイヤーから引継ぎ

大きな文字は短押し、下の小文字は長押し。右上は基本配列の位置名。点線は引継ぎ、「—」は無効です。図はキー位置の模式図です。Z単独は200ms未満で文字、200ms長押しで左Shift。Zを先に押したまま右小指の/（JISの「・」）を押すと、その瞬間にShiftが確定します。/を150ms未満で離せば「？」を入力でき、200ms待つ必要はありません。Zより先に/を押した場合や、Zを離してから/を押した場合は対象外です。200msより前に/以外を押すとZの文字入力が確定するため、「za」などは素早く打てます。他のキーへShiftをかける場合はZを200ms長押ししてから押します。/・Spaceは従来どおり文字優先の150ms判定で、短押しは文字・空白（変換）、長押しは右Shift／数字レイヤーです。

設定：z_mt は hold-preferred・200msと hold-trigger-key-positions = <50>（/位置）の組み合わせ。Windows／Mac両配列と、L3など基本配列のZを透過で引き継ぐレイヤーに適用されます。記号レイヤーのUndo／Shiftは別設定です。書き込み後は、タイピング途中のZ→/で「？」になること、Z単独・Z→Aなどの文字入力、Zの200ms長押しと/の150ms判定を確認してください。実機動作は未確認です。

02 / CONNECTION

接続先は、7つのスロットに。

接続・切断の手順

  1. 基本配列で、入力を200ms以上休める。
  2. J＋K＋L＋Enter をほぼ同時に押す（4キーを50ms以内）。
  3. 4キーをすべて離してから、下の Y / U / I / O / P / H / J を1回押す。

選ぶと接続先とOS配列が切り替わり、基本配列へ戻ります。キャンセルはEnterかEsc。J＋K＋Lだけでは中クリックです。

Y0Windows
U1Mac
I2Windows
O3Mac
P4Windows
H5Mac
J6Windows

はじめて接続する

  1. PC・タブレットのBluetooth設定を開く。
  2. J＋K＋L＋Enter → すべて離す → Y/U/I/O/P/H/Jで未登録のスロットを選ぶ。
  3. 接続先でキーボードを選び、ペアリングする。

登録済みスロットは、その接続先への再接続に使います。

L2で切断する

J＋K＋L＋Enterを押して離した後、A / S / D / F / G / Z / Xでスロット0 / 1 / 2 / 3 / 4 / 5 / 6を切断します。登録は保持します。

切断後はL2に留まります。EnterかEscで元の基本配列へ戻ります。

登録を消す操作（L2のみ）：J＋K＋L＋Enterを押して全部離し、左下段の修飾キー3つ（位置53・54・55）で現在のスロットの登録を削除。Q＋W＋E＋R で全スロットの登録を削除します。再接続には接続先側の登録も削除し、ペアリングし直してください。削除後もL2に留まるので、EnterかEscで戻ります。特定のスロットを消す場合は、その接続先を一度選んでからL2を開き直してください。単なる切断には上のA/S/D/F/G/Z/Xを使います。

設定：中央側の snippets/split-central/split-central.conf で CONFIG_BT_MAX_CONN=8・CONFIG_BT_MAX_PAIRED=8（ホスト7枠＋左右間通信用1枠）。ZMK公式設定に基づき、周辺側には適用しません。現在のビルドは右側が中央です。

書き込み後の確認：Windows／Macの両基本配列からL2を開き、Hで5（Mac）、Jで6（Windows）を選んで新しい機器とペアリングし、元の0〜4へも戻れることを確認します。Z/Xで5/6を切断した後、Enter/Escで戻れること、左右のキー入力も確認してください。

03 / SETUP

Windows / Macの設定

記号の表示は日本語（JIS）配列が前提です。英数・かなの切替はOS・IMEのキー設定に合わせてください。

Windows

  • キーボードの配列を日本語（106/109）に合わせる。言語・キーボード設定
  • キーボード側もWindows配列へ：Q＋W。
  • ジェスチャーは Win＋矢印 を送信。左右の配置が動かない場合は、設定 → システム → マルチタスクの「ウィンドウのスナップ」を確認。ショートカット一覧

Mac

  • キーボードの種類をJIS（日本語）に合わせ、キーボード側は Q＋W＋E でMac配列へ。
  • ジェスチャー用に、システム設定 → キーボード → キーボードショートカット → 修飾キーで、このキーボードの Caps Lock → Globe を設定する想定です。修飾キーの設定
  • この設定では親指Shiftの2回押しもGlobeになります。Caps Lockとして使う場合は割り当てをCaps Lockのままにし、ジェスチャーで送るキーにOS側の操作を合わせてください。
  • 画面のズームを使う場合：アクセシビリティ → ズーム機能 →「スクロールジェスチャと修飾キーを使って拡大縮小」を有効にし、使う修飾キーを選ぶ。ズームの設定

Globeの直接送信：ZMKでは &kp GLOBE を送れますが、Apple純正のFn／Globeを完全には再現しません。このキーマップのジェスチャーはCtrl＋Caps Lock＋方向キー等を送る設定なので、上記のCaps Lock → Globeを使います。ZMKのキー仕様

Macのジェスチャーの結果はOSのショートカット設定に依存します。動かないときは配列図に添えた送信キーと設定を照合してください。

左親指長押し＋右ボールでタブ切替

左親指左側（Shift・旧Bspc）を200ms長押ししてから、押したまま右ボールを動かします。左で前のタブ（Ctrl＋Shift＋Tab）、右で次のタブ（Ctrl＋Tab）。Windows／Mac共通で、Chromeなどのタブ切替ショートカットを送ります。タブの順序や対応はアプリの設定に依存します。

長押し中はL3が有効になり、上下は未割当、ポインター移動は停止。親指を離すと解除し、途中までの動きは次回へ持ち越しません。F・スクロールレイヤー（L8〜L11）との同時押しではそちらのボール操作が優先です。数字・記号レイヤーでは親指長押しでタブ切替を使えます。

親指の1回押しは次の1キーだけShift、素早い2回押しはCaps Lockのままです。MacでCaps Lock→Globeを割り当てている場合は2回押しでGlobeになります。親指の長押しや押したままの文字入力ではShiftを送らなくなるため、通常のShift長押しはZ／右小指の/を使います。別のキーを押した場合は200msを待たずにL3へ入ります。

書き込み後の確認：Windows／Macで短押しShift・2回押しCaps／Globe、200ms長押し後の左右タブ切替、上下が未割当であること、離した後のポインター復帰を確認します。短い動きで離して再度長押ししたときに前回の動きが足されないこと、Fのウィンドウ操作とEnterのスクロールの優先、左タッチパッドのMac用低速も確認してください。実機動作は未確認です。

左ミニトラックパッドのスクロール速度

接続先選択時の配列に連動して、縦横ともWindowsは従来どおり、Macは1/6の速度に切り替わります。OSの自動判別ではありません。接続先を変えずに切り替える場合は Q＋W（Windows）／Q＋W＋E（Mac）を使います。

デバイスWindowsMac
左タッチパッド（常時）1倍1/6倍
右ボール（Enter長押し中）1/2倍1/12倍

Macの記号・数字・F・スクロールレイヤー、Bluetooth管理中も低速を維持します。左タッチパッドのポインター移動やクリックには補正をかけません。右ボールのH／J／Kによる軸制限も左には適用しません。

調整箇所：snippets/input-split-listener/input-split-listener.overlay の mac-scroller 内にある &zip_scroll_scaler 1 6（分子・分母）。現在の構成では右側中央のファームウェアを書き換えると反映されます。

書き込み後の確認：同じ距離を指でなぞってWindows→Mac→Windowsで速度が変わること、Macの各レイヤーでも低速を維持することを確認します。縦横の方向・クリック、右ボールの移動・ジェスチャー・スクロールも確認してください。1/6は初期調整値で、実機での速度感は未確認です。
