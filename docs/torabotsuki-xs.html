右ボールのジェスチャー

同時押しの優先・判定時間・実機での確認

タブ切替はL3、ウィンドウ配置はL8／L9、スクロールはL10／L11。数字・記号レイヤーでも親指Shiftを長押しすればタブ切替を使えます。F・Enterの操作は親指Shiftより優先です。

タブ切替の上下は未割当。親指を離すと途中の動きをリセットします。親指は短押しして離すと次の1キーだけShift、2回でCapsを送信。押したまま別のキーを押すと200msを待たずL3に入り、Shiftは送りません。通常のShift長押しはZ／右小指の/を使います。

スクロールのH／J／Kは1回押して選択し、Enterを離すまで保持。次回は自由スクロールです。左パッドにはこの軸制限を適用しません。スクロール量はWindowsが1/2、Macが1/12です。

書き込み後はWindows／Macの基本・数字・記号レイヤーで、左右のタブ切替、Macの右Ctrl／Windowsの左Ctrl、配列を往復した後の動作を確認します。上下が未割当であること、離した後のポインター復帰、動きのリセット、F・Enterの優先、短押しShift・2回押しCapsも確認してください。実機動作は未確認です。タブの順序・対応はアプリに依存します。

同時押しコンボ

配列図の読み方

大きな文字は短押し、小文字は長押し。右上は基本配列での位置名。点線は下位配列からの引継ぎ、「—」は無効です。図はキー位置の模式図です。Zは200ms、/・Spaceは150msの文字優先判定です。

Z・/・「？」の判定と動作確認

Zと/をどちらの順でも100ms以内に重ねて押すと、Shift判定を待たずに「？」（Shift＋/）を直接送ります。入力を休める必要はなく、タイピング途中も有効。L0／L1・L3・L6〜L11で使えます。L2のBluetooth管理とL4／L5の記号レイヤーでは無効です。文字として「z・」を素早く重ねた場合も「？」になるので、文字として打つ場合はZを離してから/を押してください。

コンボが成立しない場合のZは tap-preferred・200msです。150msで文字のzがShiftになりやすかったため、Zだけ200msへ戻しています。途中でEnterなどを押しても、その時点でzに確定せず、Zを200ms押し続ければShiftになります。200ms未満でZを離すと文字のzです。100msを超えてZ＋/を押す場合は、Zを200ms保持してから/を短押しします。コンボ待ちでZ／/単独の入力が最大100ms保留される場合があります。

書き込み後はWindows／Mac両配列で、タイピング途中のZ→/と/→Zを100ms以内に重ねて「？」が1回だけ入力されること、Zと/を離して順に打てば文字になること、Z→Enterの200ms以上の保持でShift＋Enter・200ms未満でz＋Enterになることを確認します。150〜199msで離したZが文字になること、Z→Aなどの文字入力、Z／/単独の短押し・長押し、コンボが無効なL2・L4／L5の既存操作も確認してください。実機動作は未確認です。

横スクロールはセンサーのY座標0〜25%の帯から横になぞります。開始後は軸が固定されるので、縦横を変えるときは指を離します。物理的な帯の向きは取り付け方向によります。右ボールのH／J／Kの軸制限は適用しません。

速度の調整・書き込み・動作確認

調整箇所：snippets/input-split-listener/input-split-listener.overlay の通常経路にある &zip_scroll_scaler 1 6（Windows）、mac-scroller 内の &zip_scroll_scaler 1 8（Mac）。数値は分子・分母で、Macでは通常経路に重ねず置き換えて適用します。現在の構成では右側中央のファームウェアを書き換えると反映されます。

接続・切断

接続先を選ぶと、その端末用の配列にも切り替わります。

接続・切断の手順

  1. 基本配列で、入力を200ms以上休める。
  2. J＋K＋L＋Enter をほぼ同時に押す（4キーを50ms以内）。
  3. 4キーをすべて離してから、下の Y / U / I / O / P / H / J を1回押す。

選ぶと接続先とOS配列が切り替わり、基本配列へ戻ります。キャンセルはEnterかEsc。J＋K＋Lだけでは中クリックです。

はじめて接続する

  1. PC・タブレットのBluetooth設定を開く。
  2. J＋K＋L＋Enter → すべて離す → Y/U/I/O/P/H/Jで未登録のスロットを選ぶ。
  3. 接続先でキーボードを選び、ペアリングする。

登録済みスロットは、その接続先への再接続に使います。

L2で切断する

J＋K＋L＋Enterを押して離した後、A / S / D / F / G / Z / Xでスロット0 / 1 / 2 / 3 / 4 / 5 / 6を切断します。登録は保持します。

切断後はL2に留まります。EnterかEscで元の基本配列へ戻ります。

登録を消す操作（L2のみ）：J＋K＋L＋Enterを押して全部離し、左下段の修飾キー3つ（位置53・54・55）で現在のスロットの登録を削除。Q＋W＋E＋R で全スロットの登録を削除します。再接続には接続先側の登録も削除し、ペアリングし直してください。削除後もL2に留まるので、EnterかEscで戻ります。特定のスロットを消す場合は、その接続先を一度選んでからL2を開き直してください。単なる切断には上のA/S/D/F/G/Z/Xを使います。

設定：中央側の snippets/split-central/split-central.conf で CONFIG_BT_MAX_CONN=8・CONFIG_BT_MAX_PAIRED=8（ホスト7枠＋左右間通信用1枠）。ZMK公式設定に基づき、周辺側には適用しません。現在のビルドは右側が中央です。

書き込み後の確認：Windows／Macの両基本配列からL2を開き、Hで5（Mac）、Jで6（Windows）を選んで新しい機器とペアリングし、元の0〜4へも戻れることを確認します。Z/Xで5/6を切断した後、Enter/Escで戻れること、左右のキー入力も確認してください。

OS側の設定

配列・入力ソース・ウィンドウ操作を確認。

記号の表示は日本語（JIS）配列が前提です。英数・かなの切替はOS・IMEのキー設定に合わせてください。

Windows

  • キーボードの配列を日本語（106/109）に合わせる。言語・キーボード設定
  • キーボード側もWindows配列へ：Q＋W。
  • ジェスチャーは Win＋矢印 を送信。左右の配置が動かない場合は、設定 → システム → マルチタスクの「ウィンドウのスナップ」を確認。ショートカット一覧

Mac

  • キーボードの種類をJIS（日本語）に合わせ、キーボード側は Q＋W＋E でMac配列へ。
  • 追加ソフトを使わない日英トグル：ZMKで1キーに &kp RC(SPACE) を割り当てると、右Ctrl＋Spaceを送れます。macOSの「前の入力ソースを選択」を利用する方法です。日本語とABCの2ソースで使い、この標準ショートカットを有効にします。Appleの入力ソース切替仕様
  • 現在の配列との差：Space右隣は短押しで左Ctrl、長押しでL9です。同じ位置を追加ソフト不要にする場合の置換候補は &lt 9 RC(SPACE)。このガイドの修正ではキー割り当ては変更していません。S＋Fの英数・J＋Lのかなは、それぞれ直接指定です。
  • トグルの範囲：右Ctrl＋Spaceは直前の入力ソースへの切替です。3ソース以上の中から必ず日英だけを往復する保証や、Macの現在の入力モードをZMK側で取得して判定する仕組みではありません。
  • ウィンドウ配置ジェスチャー用に、システム設定 → キーボード → キーボードショートカット → 修飾キーで、このキーボードの Caps Lock → Globe を設定する想定です。修飾キーの設定
  • Capsを入力切替に使う設定とは競合する場合があります。Capsの単独押しと右Ctrl＋Capsを区別できる設定が必要です。親指Shiftの2回押しもCapsを送るので、結果はMac側の設定によって入力切替／Globe／Caps Lockになります。
  • 画面のズームを使う場合：アクセシビリティ → ズーム機能 →「スクロールジェスチャと修飾キーを使って拡大縮小」を有効にし、使う修飾キーを選ぶ。ズームの設定

Globeの直接送信：ZMKでは &kp GLOBE を送れますが、Apple純正のFn／Globeを完全には再現しません。このキーマップのウィンドウ操作ジェスチャーはCtrl＋Caps Lock＋方向キー等を送る設定なので、上記のCaps Lock → Globeを使います。ZMKのキー仕様

キーの動き・送信キーは配列直下のジェスチャー一覧で確認できます。この欄ではMac側の割り当てだけを設定します。

設定元：キーマップ ／ 右ボール ／ README。Studioで実機を変更した場合は図と異なることがあります。
