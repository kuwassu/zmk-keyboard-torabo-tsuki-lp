
[torabo-tsuki LP](https://github.com/sekigon-gonnoc/torabo-tsuki-lp)用のZMKファームウェア

* _centralがついているuf2をトラックボールがついている方に、_peripheralを反対側に書き込んでください
* キーマップはkeymap-editorおよびzmk-studioで編集できます

キーバインド・レイヤー・同時押しコンボの図解は [torabotsuki-xs 操作ガイド](docs/torabotsuki-xs.html) をブラウザーで開いて確認できます。

英数は左手の `S + F`、かなは右手の `J + L`。ホームポジションの人差し指と薬指で、間のキーを飛ばして同時押しします（L0 / L1 / L6 / L7で有効）。基本配列では `J + K + L` が中クリックなので、かなの操作ではKを押さないようにします。

右ボールのジェスチャーはFレイヤー（L8 / L9）だけで有効です。数字レイヤーでは通常のポインター移動です。

Enter長押しのスクロールレイヤー（L10 / L11）では、`J`を1回押すと右ボールの縦スクロールのみ、`K`で横のみ、`H`で縦横自由に切り替えます。H / J / Kを離してもモードを保持し、Enterを離すと解除。次回は自由スクロールから始まります。速度はWindowsが1/2、Macが1/12のままです。左ミニトラックパッドにはこの軸制限を適用しません。Enterを押したまま `U` で画面の明るさ−（`C_BRI_DN`）、`O` で明るさ＋（`C_BRI_UP`）。`M / , / .` の音量−・ミュート・音量＋と同じく、Windows／Mac共通です。

接続先の切替は、基本配列で `J + K + L + Enter` を同時押しして全キーを離し、`Y / U / I / O / P / H / J` でスロット `0 / 1 / 2 / 3 / 4 / 5 / 6` を選びます。選択後は対応するWindows／Macの基本配列に戻ります。選択前なら `Enter` または `Esc` でキャンセルできます。コンボは直前200ms入力なし・4キーを50ms以内の条件で有効です。Enter長押し中は接続先を切り替えません。

Bluetoothは7スロット（0〜6）です。0・2・4・6はWindows、1・3・5はMac配列に戻ります。中央側専用の `snippets/split-central/split-central.conf` で `CONFIG_BT_MAX_CONN=8` と `CONFIG_BT_MAX_PAIRED=8` を設定し、ホスト7枠＋左右間通信用1枠を確保しています（[ZMK公式設定](https://zmk.dev/docs/config/system#bluetooth)）。現在の `build.yaml` では右側が中央、左側が周辺です。

Bluetoothの切断・登録削除もL2に集約しました。A / S / D / F / G / Z / Xでスロット0〜6を切断、左下段の修飾キー3つ（位置53・54・55）で現在の登録、Q + W + E + Rで全登録を削除します。切断・削除後はL2に留まるのでEnterかEscで戻ります。L10 / L11はスクロール・メディア操作用です。配列切替コンボはL0・L1の両方で有効です。Q + WでWindows、Q + W + EでMacへ、接続先を変えずに配列だけ切り替えます。

次の1キーだけShiftにするには `S + D + F` を50ms以内に同時押しして離します（L0 / L1 / L6 / L7）。1500ms以内の次のキーに適用されます。長押しや入力前の待ち時間は不要です。既存の `S + F` は英数なので、ShiftではDも押します。

低速マウスは廃止しました。L3は既存の番号を保つため空きとして残しています。左親指左側（旧Bspc）でもShiftを使えます。短押し1回で次の1キーだけShift、素早く2回でCaps Lockのオン／オフ（連打の判定200ms）。単押しは最大200ms後、または別のキーを押した時点で確定し、確定後1500ms以内の次のキーにShiftが付きます。200ms以上の長押し、または押したまま別のキーを押すと通常のShiftです。基本配列のZと右小指の/（JISの「・」）は同じtap-preferred・150ms判定です。150ms未満で離すと文字、150ms長押しで左右のShiftになります。直前入力・再タップによる文字優先条件は設けません。Zで「？」を入力するときは、Zを150ms押してから/を短押しします。記号レイヤー（L4 / L5）のZ位置は短押しでUndo・長押しで左Shift、/位置は右Shiftです。親指Shiftは透過キーで引き継ぎます。Macの記号レイヤーではR位置がEnterです（WindowsはF2）。Backspaceは右下段に残しています。

Macで設定すること一覧
- キーボード > キーボードショットカット > 装飾キー > Caps Lock → Globe（この設定では親指Shiftの2回押しもGlobeになります。Caps Lockとして使う場合はCaps Lockのままにしてください）
- ズーム機能 > スクロールジェスチャと装飾キーを使って拡大縮小

Fレイヤー（L8 / L9）の閉じる操作は `A + S + D` の3キー同時押しです（直前150ms入力なし・50ms以内）。WinはAlt＋F4、MacはCmd＋Qを送信します。旧H位置の単独操作は無効にしました。

Spaceの数字レイヤー切替（L0 / L1）は専用のtap-preferred・150ms判定です。150ms未満で離せば、次のキーと押す時間が重なっても空白・変換になります。150ms長押しでL6 / L7へ入ります。他のレイヤーキーのhold-preferred設定は変更していません。確認時はWindows／Mac両配列で、素早い変換と150ms長押し後の数字入力、Z・/の文字入力とShiftを確かめてください。
