
[torabo-tsuki LP](https://github.com/sekigon-gonnoc/torabo-tsuki-lp)用のZMKファームウェア

* _centralがついているuf2をトラックボールがついている方に、_peripheralを反対側に書き込んでください
* キーマップはkeymap-editorおよびzmk-studioで編集できます

キーバインド・レイヤー・同時押しコンボの図解は [torabotsuki-xs 操作ガイド](docs/torabotsuki-xs.html) をブラウザーで開いて確認できます。

英数は左手の `S + F`、かなは右手の `J + L`。ホームポジションの人差し指と薬指で、間のキーを飛ばして同時押しします（L0 / L1 / L6 / L7で有効）。基本配列では `J + K + L` が中クリックなので、かなの操作ではKを押さないようにします。

右ボールのジェスチャーは、Space長押しの数字レイヤー（L6 / L7）と、Space右隣長押しのFレイヤー（L8 / L9）で有効です。この間は通常のポインター移動が止まります。スクロールレイヤーも同時に有効な場合は、既存の定義順どおりジェスチャーが優先されます。

Enter長押しのスクロールレイヤー（L10 / L11）では、`J`を1回押すと右ボールの縦スクロールのみ、`K`で横のみ、`H`で縦横自由に切り替えます。H / J / Kを離してもモードを保持し、Enterを離すと解除。次回は自由スクロールから始まります。速度はWindowsが1/2、Macが1/12のままです。左ミニトラックパッドにはこの軸制限を適用しません。

接続先の切替は、基本配列で `H + J + K` を同時押しして全キーを離し、`Y / U / I / O / P` でスロット `0 / 1 / 2 / 3 / 4` を選びます。選択後は対応するWindows／Macの基本配列に戻ります。選択前なら `Enter` または `Esc` でキャンセルできます。コンボは直前200ms入力なし・3キーを50ms以内の条件で有効です。Enter長押し中は接続先を切り替えません。

Bluetoothの切断・登録削除もL2に集約しました。A / S / D / F / Gでスロット0〜4を切断、左下段の修飾キー3つ（位置53・54・55）で現在の登録、Q + W + E + Rで全登録を削除します。切断・削除後はL2に留まるのでEnterかEscで戻ります。L10 / L11はスクロール・音量操作用です。配列切替コンボはL0・L1の両方で有効です。Q + WでWindows、Q + W + EでMacへ、接続先を変えずに配列だけ切り替えます。

低速マウスは廃止しました。L3は既存の番号を保つため空きとして残しています。Shiftは左親指左側（旧Bspc）に集約しました。短押し1回で次の1キーだけShift、素早く2回でCaps Lockのオン／オフ（連打の判定200ms）。単押しは最大200ms後、または別のキーを押した時点で確定し、確定後1500ms以内の次のキーにShiftが付きます。200ms以上の長押し、または押したまま別のキーを押すと通常のShiftです。Zと右小指の/は文字専用。記号レイヤーでもZ位置はUndo専用、/位置は基本配列の/を引き継ぎます。Backspaceは右下段に残しています。

Macで設定すること一覧
- キーボード > キーボードショットカット > 装飾キー > Caps Lock → Globe（この設定では親指Shiftの2回押しもGlobeになります。Caps Lockとして使う場合はCaps Lockのままにしてください）
- ズーム機能 > スクロールジェスチャと装飾キーを使って拡大縮小

Fレイヤー（L8 / L9）の閉じる操作は `A + S + D` の3キー同時押しです（直前150ms入力なし・50ms以内）。WinはAlt＋F4、MacはCmd＋Qを送信します。旧H位置の単独操作は無効にしました。
