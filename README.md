
[torabo-tsuki LP](https://github.com/sekigon-gonnoc/torabo-tsuki-lp)用のZMKファームウェア

* _centralがついているuf2をトラックボールがついている方に、_peripheralを反対側に書き込んでください
* キーマップはkeymap-editorおよびzmk-studioで編集できます

ローカルビルドはDocker Desktopを起動し、`powershell -ExecutionPolicy Bypass -File .\scripts\build-local.ps1` を実行します。UF2は `.local-build/firmware/` に出力されます。[ローカルビルド手順](docs/local-build.md)に左右の個別ビルド・キャッシュ更新をまとめています。GitHub Actionsは手動実行のみです。

[DYA Studio対応](docs/dya-studio.md)：ZMK v0.3ベースで、配列・Bluetooth接続先・左右のアイドル／スリープ時間・右ボールと左パッドの調整に対応します。右側をUSB接続し、接続管理 `J＋K＋L＋Enter` → 左親指Shift位置でStudioを解除してから接続します。左右とも対応版を書き込んでください。

キーバインド・レイヤー・同時押しコンボの図解は [torabotsuki-xs 操作ガイド](docs/torabotsuki-xs.html) をブラウザーで開いて確認できます。配列図を上段の全幅に表示し、下段で右ボールのジェスチャーと同時押しコンボを並べています。ページは操作早見、ポインティング操作、Bluetooth接続・切替、OS初期設定、詳細仕様・開発者メモの順です。判定時間・設定ファイル・書き込み後の検証は末尾の開発者メモに集約しています。構成の根拠と確認項目は [docsのデザイン方針](docs/design-notes.md) にまとめています。

英数は左手の `S + F`、かなは右手の `J + L`。ホームポジションの人差し指と薬指で、間のキーを飛ばして同時押しします（L0 / L1 / L6 / L7で有効）。基本配列では `J + K + L` が中クリックなので、かなの操作ではKを押さないようにします。

右ボールのウィンドウ操作ジェスチャーはFレイヤー（L8 / L9）で有効です。左親指左側（Shift・旧Bspc）を押している間、通常の左ShiftとL3のタブ切替ジェスチャーが有効になります。押したまま右ボールを左へ動かすと前のタブ、右へ動かすと次のタブへ移動します。Windowsは左Ctrl＋Shift＋Tab／左Ctrl＋Tab、Macは右Ctrl＋Shift＋Tab／右Ctrl＋Tabを送ります。Mac配列のL1が有効なら、数字・記号レイヤーを重ねても右Ctrlを使います。上下は未割当で、この間はポインター移動が止まります。離すと解除し、次回は途中までの動きを引き継ぎません。F・スクロールレイヤー（L8〜L11）との同時押しではそちらのボール操作が優先です。数字レイヤーでは通常のポインター移動ですが、親指Shiftも保持するとタブ切替になります。タブの切替順序や対応はアプリに依存します。

Enter長押しのスクロールレイヤー（L10 / L11）では、`J`を1回押すと右ボールの縦スクロールのみ、`K`で横のみ、`H`で縦横自由に切り替えます。H / J / Kを離してもモードを保持し、Enterを離すと解除。次回は自由スクロールから始まります。速度はWindowsが1/2、Macが1/12のままです。左ミニトラックパッドにはこの軸制限を適用しません。Enterを押したまま `U` で画面の明るさ−（`C_BRI_DN`）、`O` で明るさ＋（`C_BRI_UP`）。`M / , / .` の音量−・ミュート・音量＋と同じく、Windows／Mac共通です。

接続先の切替は、基本配列で `J + K + L + Enter` を同時押しして全キーを離し、`Y / U / I / O / P / H / J` でスロット `0 / 1 / 2 / 3 / 4 / 5 / 6` を選びます。選択後は対応するWindows／Macの基本配列に戻ります。選択前なら `Enter` または `Esc` でキャンセルできます。コンボは直前200ms入力なし・4キーを50ms以内の条件で有効です。Enter長押し中は接続先を切り替えません。

左ミニトラックパッドの縦横スクロール速度も配列に連動します。Windows（L0）は補正なしの1/6倍（以前のMac相当）、Mac（L1）は1/8倍（以前のMacより25%低速）です。キーの長押しは不要で、指を縦横になぞるとスクロールします。OSの自動判別ではなく、接続先選択後の配列、または `Q + W`／`Q + W + E` の配列切替で変わります。Windows／Macとも各レイヤーで速度を維持します。MacではL1が有効な間、専用の補正を適用します。設定は `snippets/input-split-listener/input-split-listener.overlay` の通常経路の `<&zip_scroll_scaler 1 6>`（Windows）と `mac-scroller` 内の `<&zip_scroll_scaler 1 8>`（Mac）で調整できます。数値は分子・分母で、Macの補正は通常経路に重ねず置き換えます。右ボールとは独立した補正で、ポインター移動・クリックは補正しません。現在の構成では右側中央のファームウェアを書き換えれば反映されます。書き込み後は同じ距離を指でなぞり、Windows→Mac→Windowsの切替、両OSの各レイヤーでの速度維持、縦横・方向・クリックと右ボールの操作を実機で確認してください。

Bluetoothは7スロット（0〜6）です。0・2・4・6はWindows、1・3・5はMac配列に戻ります。中央側専用の `snippets/split-central/split-central.conf` で `CONFIG_BT_MAX_CONN=8` と `CONFIG_BT_MAX_PAIRED=8` を設定し、ホスト7枠＋左右間通信用1枠を確保しています（[ZMK公式設定](https://zmk.dev/docs/config/system#bluetooth)）。現在の `build.yaml` では右側が中央、左側が周辺です。

Bluetoothの切断・登録削除もL2に集約しました。A / S / D / F / G / Z / Xでスロット0〜6を切断、左下段の修飾キー3つ（位置53・54・55）で現在の登録、Q + W + E + Rで全登録を削除します。切断・削除後はL2に留まるのでEnterかEscで戻ります。L10 / L11はスクロール・メディア操作用です。配列切替コンボはL0・L1の両方で有効です。Q + WでWindows、Q + W + EでMacへ、接続先を変えずに配列だけ切り替えます。

ワンショットShiftは使いません。旧 `S + D + F` のコンボも削除しました。左親指はマクロを使わず、専用ビヘイビア `torabo,behavior-thumb-shift` で通常のShiftとタブ切替ジェスチャーを保持中だけ有効にします。

「？」の専用コンボは `Z + /`（JISの「・」、位置39＋50）です。どちらの順でも100ms以内に重ねて押すと `Shift + /` を直接送ります。直前入力の待ち時間は0msなのでタイピング途中も有効です。L0 / L1・L3・L6〜L11で使えます。L2のBluetooth管理とL4 / L5の記号レイヤーでは無効です。コンボが成立しないときのZは200ms、/は150msのtap-preferredで、Z＋Enterの判定方法も維持します。100msを超えてZ＋/を押す場合はZを200ms保持してから/を短押しします。文字として「z・」を素早く重ねた場合も「？」になるため、文字として打つ場合はZを離してから/を押します。コンボ待ちでZ／/単独の入力が最大100ms保留される場合があります。

コンボの書き込み後確認：Windows／Macのタイピング途中でZ→/と/→Zを100ms以内に重ね、「？」が1回だけ入力されることを確認します。Zと/を離して順に打った文字入力、Z→A、Z→Enterを重ねてZを200ms以上保持したShift＋Enter、200ms未満で離したz＋Enter、Z／/単独の短押し・長押しも確認します。L2のBluetooth管理とL4 / L5のUndo／Shiftに影響がないことも確認してください。実機動作は未確認です。

低速マウスは廃止しました。空きだったL3はタブ切替ジェスチャー用に使います。左親指左側（旧Bspc）は押した瞬間から離すまで通常の左Shiftとして働きます。1回押しのワンショットShiftと2回押しのCaps Lockは廃止しました。押したまま文字キーでShift入力、右ボールを左右へ動かすとタブ切替です。ジェスチャーも押下時に有効になり、200msの待ちはありません。タブ切替の送信中だけ保持中のShiftをマスクし、右方向が前のタブに反転するのを防ぎます。基本配列のZはtap-preferred・200ms、右小指の/（JISの「・」）はtap-preferred・150ms判定です。それぞれ判定時間未満で離すと文字、Zは200ms長押しで左Shift、/は150ms長押しで右Shiftになります。直前入力・再タップによる文字優先条件は設けません。「？」はZ＋/（JISの「・」）を100ms以内に重ねて押す専用コンボでも入力できます。記号レイヤー（L4 / L5）のZ位置は短押しでUndo・長押しで左Shift、/位置は右Shiftです。親指の通常Shift・保持中のタブ切替は透過キーで引き継ぎます。Macの記号レイヤーではR位置がEnterです（WindowsはF2）。Backspaceは右下段に残しています。

Macの入力ソース切替の代替案：ZMKの `&kp RC(SPACE)` で右Ctrl＋Spaceを送れます。macOS標準の「前の入力ソースを選択」を有効にし、日本語とABCの2入力ソースで使う方法ですが、選択表示や待ちが生じ、Windowsの半角／全角と同じ即時トグルにはなりません（[Appleの仕様](https://support.apple.com/ja-jp/guide/mac-help/mchlp1406/mac)）。Space右隣の長押しL9を残す場合は `&lt 9 RC(SPACE)` が置換候補です。現在の割り当ては `&lt 9 LCTRL` のままで、このdocs修正では変更していません。3ソース以上の中から日英だけを選ぶ保証や、Macの入力モードをZMKで取得して判定する仕組みではありません。

Macで設定すること一覧
- キーボード > キーボードショットカット > 装飾キー > Caps Lock → Globe（ウィンドウ配置用。Capsの入力切替と競合する場合は単独押しと組み合わせを区別してください）
- ズーム機能 > スクロールジェスチャと装飾キーを使って拡大縮小

Fレイヤー（L8 / L9）の閉じる操作は `A + S + D` の3キー同時押しです（直前150ms入力なし・50ms以内）。WinはAlt＋F4、MacはCmd＋Qを送信します。旧H位置の単独操作は無効にしました。

Spaceの数字レイヤー切替（L0 / L1）は専用のtap-preferred・150ms判定です。150ms未満で離せば、次のキーと押す時間が重なっても空白・変換になります。150ms長押しでL6 / L7へ入ります。他のレイヤーキーのhold-preferred設定は変更していません。確認時はWindows／Mac両配列で、素早い変換と150ms長押し後の数字入力、Zの200ms・/の150ms判定での文字入力とShiftを確かめてください。

タブ切替の書き込み後確認：基本配列と数字・記号レイヤーでMacは右Ctrl、Windowsは左Ctrlの送信を確認し、Windows→Mac→Windowsの配列切替後も確認します。現在の構成では右側中央のファームウェアを書き換えると反映されます。Windows／Macの両配列で、親指保持＋A／EnterのShift入力、解放後の通常入力、2回押しでCapsが切り替わらないこと、保持中の左右タブ切替、未割当の上下でタブが切り替わらないこと、親指を離した後のポインター復帰を確認します。短い動きで離して再度長押しした際に前回の動きが足されないこと、Fのウィンドウ操作とEnterのスクロールが優先されること、左タッチパッドのMac用低速も確認してください。実機動作は未確認です。
